VectisDHG Compagnon (iPhone) — consultation + post-it

CE QUE FAIT L'APPLICATION
- Consulter : dotation, heures ventilées, reste à utiliser, services à ventiler, disciplines, enseignants.
- Modifier uniquement les post-it des disciplines.
- Tout reste sur le téléphone : aucune donnée n'est envoyée sur Internet.

MISE EN PLACE (une seule fois)
Une application web installable doit être servie en https. Déposez le dossier tel quel sur un hébergement statique
gratuit de votre choix (GitHub Pages, Netlify, serveur de l'établissement…). Aucune donnée n'y est stockée :
seuls les fichiers de l'application y sont déposés.
Sur l'iPhone : ouvrir l'adresse dans Safari › Partager › « Sur l'écran d'accueil ». Elle fonctionne ensuite hors connexion.

UTILISATION
1. Dans VectisDHG Autonomie : Fichier › Enregistrer, puis envoyer le .json sur l'iPhone (AirDrop, mail, iCloud Drive…).
2. Dans le Compagnon : onglet Fichier › Ouvrir un fichier .json.
3. Modifier les post-it (onglet Post-it ou depuis une discipline) : enregistrement automatique sur le téléphone.
4. Onglet Fichier › Exporter le fichier mis à jour (feuille de partage : AirDrop, mail, Fichiers…).
5. Dans VectisDHG Autonomie : Fichier › Ouvrir ce fichier.
ATTENTION : le fichier exporté remplace l'ancien. Ne modifiez pas l'application sur l'ordinateur entre l'envoi et le
retour du fichier, sinon ces modifications seraient perdues.

AVEC NUAGE (APPS ÉDUCATION) OU UN AUTRE NEXTCLOUD
L'application ne se connecte pas directement à Nuage : le serveur n'autorise pas l'accès depuis une page web.
Le fichier .json peut en revanche y être stocké :
- iPhone : installer l'application Nextcloud et la connecter à Nuage (adresse du serveur + mot de passe d'application créé dans
  Nuage > Paramètres > Sécurité). Les fichiers de Nuage apparaissent dans l'app Fichiers. Dans le Compagnon :
  onglet Fichier > Ouvrir un fichier .json > choisir la sauvegarde dans Nuage.
- Retour des post-it : onglet Fichier > Exporter le fichier mis à jour > « Enregistrer dans Fichiers » > Nuage, en
  remplaçant l'ancien fichier.
- Ordinateur : client de synchronisation Nextcloud ; avec Chrome ou Edge, Fichier > Ouvrir puis Enregistrer (Ctrl+S) met à jour
  le fichier sur place dans le dossier synchronisé (voir la Notice de VectisDHG Autonomie).
Évitez de modifier le même fichier sur deux appareils en même temps.
